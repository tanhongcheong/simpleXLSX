[basic_XLSX_writer.hpp](basic_XLSX_writer.hpp) is a single header file that allows you create .xlsx file with some formatting.\
It requires [libzip](https://libzip.org/).\
\
See [WriteExample.cpp](WriteExample.cpp) for example of the formatting available and how to use it.

[basic_XLSX_reader.hpp](basic_XLSX_reader.hpp) is a single header file that allows you to read the content on a xlsx file.\
It requires [libzip](https://libzip.org/) and [tinyxml2](https://github.com/leethomason/tinyxml2).\
\
See [ReadExample.cpp](ReadExample.cpp) for example on how to read the content of a xlsx file.
